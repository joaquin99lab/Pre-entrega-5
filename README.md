# Loop & Lina Crochet

Sitio web de Loop & Lina, un emprendimiento de tejidos de crochet hechos a mano. Presenta la marca, sus productos y sus canales de contacto.

## Páginas

- Inicio: presentación y galería de creaciones.
- Sobre mí: historia del emprendimiento.
- Productos: catálogo de tejidos.
- Preguntas frecuentes: información sobre productos y pedidos.
- Contacto: canales para realizar consultas.

## Tecnologías

- HTML5 y CSS3.
- Bootstrap 5.3.8 por CDN.
- CSS Grid y Flexbox para el diseño adaptable.
